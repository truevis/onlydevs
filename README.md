# Onlydevs

Meetup demo for Grok Bot, Cursor, and GitHub integration.

## Streamlit spider chart

Creative city-radar sample using [streamlit-echarts](https://github.com/andfanilo/streamlit-echarts):

```bash
cd C:\GitHub\onlydevs
pip install -r requirements.txt
streamlit run app.py
```

Open the app, toggle cities, and watch the spider chart overlay like a market-profiles radar.
